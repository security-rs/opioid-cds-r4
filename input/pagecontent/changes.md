### 2022.1.1 - Technical Correction

* This release updates the value set definitions for all value sets to specify computable definitions (i.e. using the `compose` element), where previously the definitions were specified as narrative instructions. The resulting expansions have been verified identical to the previous publication.

### 2022.1.0 - Stable Release

After several years of development and piloting the content in this implementation guide at multiple clinical sites, this publication is the accumulation of the feedback incorporated from those piloting efforts. The content is considered stable and ready for use. Documentation of pilot efforts is available in the [Pilot Testing Reports](https://fhir.org/guides/cdc/opioid-cds/documentation.html#pilot-testing-reports) topic on the documentation page.
